## 📌 Sobre o Projeto
Este programa em Python foi desenvolvido para a campanha de conscientização ambiental da companhia de saneamento municipal. Ele classifica o perfil de consumo dos imóveis com base no seu tipo ("comercial", "casa" ou "apartamento") e no consumo mensal de água em metros cúbicos ($m^3$), emitindo alertas educativos automáticos aos moradores.
